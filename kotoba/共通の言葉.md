# 共通の言葉

masato-yatake・everyone-seed・yatakeblog-beep のどのリポジトリでも使う言葉の正本。製品の中だけの言葉は、その製品のリポジトリの言葉のパーツリストに置く（例：everyone-seed/EINOW の docs/言葉のパーツリスト.md）。
ここに無い言葉を新しく使うときは、かんばんの報告に「新しく使った言葉」として1行ずつ書き、Masato が ○ を付けたものだけをここに足す。

## 人と道具

| 言葉 | 意味 | 使わない言い方 |
|---|---|---|
| Claude | チャットの Claude（かんばんを書く・報告を読み合わせる・見張る） | Fable |
| CC | Claude Code（かんばんを受けて作業する） | — |
| ローカル CC | Windows の Claude Code | — |
| worktree | CC が作業のたびに作る別フォルダ | — |
| API | ほかのプログラムがデータを取りに行く・書きに行く先。URL を添える | 口・道・入口 |

## かんばんと PR

| 言葉 | 意味 | 使わない言い方 |
|---|---|---|
| かんばん | CC への指示書（1枚の HTML） | — |
| 止まる条件 | 当たったら CC が作業せず報告する条件 | — |
| 【止まり】 | 判断が要って止まった PR の題名の頭に付ける印 | — |
| 検証の結果 | PR 本文の「■ 検証の結果」（そのかんばんの分だけ） | — |
| 全体テストの結果 | CC が手元でテストを全部流した結果を PR のコメントに貼ったもの。自動マージが見る | 合格札 |
| 自動マージ | 条件を全部満たした PR を GitHub Actions がマージする仕組み | — |
| 言葉の検査 | PR の題名・本文と足した .md の行を、この表のやめる言い方で検査する仕組み | — |
| 持ち帰り論点 | CC がチャットで決めてほしいと返したこと | — |
| 並行作業：可／不可 | 同時に動かしてよいか | — |
| 周 | 歩くループで、歩いて確かめて1つ直す1回分 | — |

## 操作の言葉

| 言葉 | 意味 | 使わない言い方 |
|---|---|---|
| クリック／クリックできない | パソコンの画面の操作 | 押す／押せない |
| タップ／タップできない | スマホの画面の操作 | 押す／押せない |
| 出力する | ファイルにして外に出す | 出す |
| 表示する／表示される | 画面に現れる | 出す／出る |

## やめる言い方

押す・押せない／口・道・入口・一本道／箱／軸／中身／記録（→保存）／出す（→出力・表示）／見立て（→Claude の考え）／Fable（→Claude）／①②などの札／合格札（→全体テストの結果）
